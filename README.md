# VibeSync
VibeSync keeps it real.Helps plan your day in 3 parts:morning,afternoon and evening.Track your vibe and stay on top of your game.
 Features
- Select a time of day from the dropdown (spinner).
- Get a suggestion for a quick activity/message to share with friends or family.
- Reset the suggestion with a tap.

 Code Structure
- `MainActivity.kt`: Handles UI logic and spinner interactions.
- `activity_main.xml`: Layout file for the app's UI.
